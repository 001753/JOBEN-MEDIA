Analisis Referensi Script vs JOBEN NEWS
Cara Kerja Referensi
Script ini pakai pola "Build di Replit → Push ke GitHub → Pull di cPanel":

Replit = tempat development & build (npm run build)
GitHub = jembatan (hasil build di-commit juga)
cPanel = server produksi, cukup git pull + restart
CPanel-nya pakai Phusion Passenger sebagai process manager — ini yang otomatis dimiliki hampir semua cPanel hosting dengan fitur Node.js Selector (seperti yang terlihat di screenshot kamu: mp.jobenapp.cloud).

Bisa Diterapkan ke JOBEN NEWS?
Bisa, tapi JOBEN NEWS lebih kompleks — ini monorepo dengan 2 aplikasi Node.js terpisah:

Komponen	Referensi Script	JOBEN NEWS
Framework	Next.js standalone	Next.js 14 (frontend) + Strapi v5 (backend)
Database	Prisma + PostgreSQL	SQLite (dev) / PostgreSQL (prod)
Proses	1 app Node.js	2 app Node.js terpisah
Upload	-	AWS S3
Artinya di cPanel kamu perlu 2 Node.js Application di Node.js Selector:

mp.jobenapp.cloud → Next.js frontend (server.js dari standalone build)
api.jobenapp.cloud (atau subdomain lain) → Strapi CMS backend
Data yang Dibutuhkan Sebelum Bisa Dibuat Script
A. Info cPanel Hosting kamu:

SSH hostname & username (untuk test koneksi)
Apakah hosting punya PostgreSQL? (SQLite tidak cocok untuk produksi)
Versi Node.js yang tersedia di Node.js Selector (screenshot menunjukkan 22 — bagus)
Berapa RAM & proses limit? (Strapi v5 butuh ~300-500MB)
B. Struktur domain yang diinginkan:

Frontend di domain mana? (jobenapp.cloud? www.jobenapp.cloud?)
Strapi API di subdomain mana? (api.jobenapp.cloud? cms.jobenapp.cloud?)
C. Storage untuk upload media Strapi:

Tetap pakai AWS S3? (sudah ada konfigurasinya di project)
Atau pakai local storage di cPanel?
D. Database production:

Sudah ada PostgreSQL database di cPanel? (host, nama DB, user, password)
Atau pakai SQLite saja di cPanel? (lebih mudah tapi tidak ideal)
E. GitHub repo:

URL repo GitHub project ini (untuk git pull di cPanel)
Apakah .next/standalone dan Strapi build output mau di-commit ke git? (seperti referensi) atau pakai cara lain?
